# 奖状方案制作单

复制这份制作单，填好后与需要使用的图片、名单和获奖表放在同一个文件夹。若沿用示例中的文字或排版，可直接写“沿用样例”。

| 项目 | 我的填写 |
| --- | --- |
| 证书标题 | 荣誉证书 |
| 主办单位 | 【主办单位】 |
| 活动名称 | 【活动名称】 |
| 正文 | 在【主办单位】举办的“【活动名称】”中表现优异，作品《{作品名}》 |
| 奖项行 | 被评为“{奖项}” |
| 成员行 | 小组成员： {组员} |
| 名单说明 | （按照姓氏首字母排序） |
| 发证单位 | 【发证单位】 |
| 落款日期 | 例如 2026年11月，可在工作台修改 |
| 背景与排版 | 默认横版，沿用样例边框与字号；如需改动，请注明位置、字号和对齐方式 |

## 载入与替换

在「证书文本与布局 → 载入方案」选择同目录的“通用奖状方案.json”。选中“活动正文”和“发证单位与日期”，将【】连同括号替换为实际文字。换行可以直接在文字框中输入。完成后用“保存方案…”另存。

大括号是程序变量。{组号} 为数字，{组别} 为完整组名，{作品名}、{奖项}、{组员} 和 {日期} 在预览与批量导出时填入。名单表按“组别、作品名称、组员1、组员2……”填写，获奖表按“奖项、组别”填写。可以直接改随附的两份 CSV。

方案 JSON 的 x、y、width 均为画布百分比。y 对应文字上沿，x 按左、中、右对齐方式对应文字的左边、中点或右边。pt 是字号，visible 控制显示。
